Cursor Prompt — Botamin Call Growth Dashboard smol
Build a complete working Streamlit product for the Botamin Product Owner AI-product test assignment.
The product must run locally, be demo-ready, and must not require external AI API keys.
The goal is to help a Botamin analyst turn a raw Excel export of sales bot calls into a clear product decision:
* how the project is performing;
* where the bot loses clients;
* whether the main loss is technical or script-related;
* what metric proves it;
* which calls should be checked manually;
* what first A/B test should be launched.
Core flow:
Excel → validation → preprocessing → local analysis → funnel → drop-off → adaptive overview → main growth opportunity → first A/B test → Ask the Dashboard → optional local Gemma helper → CSV export

6. Funnel stages
Classify each call into the maximum reached stage:
0_no_dialog
1_contact_greeting
2_consent_permission
3_offer_delivered
4_relevance_signal_detected
5_next_step_proposed
6_next_step_accepted
7_context_collected_or_correctly_finished


Use transparent rule-based keyword logic.
The original bot tasks are:
1. Greet and get permission to talk.
2. Tell about the offer.
3. Agree on a meeting.
4. Qualify the client.
Interpret this as a B2B sales funnel.
Do not treat “meeting” too literally.
A meaningful next step can be:
* meeting;
* demo;
* expert call;
* manager callback;
* sending materials;
* call later;
* decision-maker contact;
* another meaningful continuation.
Qualification may happen before or after next-step agreement.
The real problem is when the bot proposes or gets a next step without any relevance signal.

10. Main metric
Main metric:
Qualified Next Step Rate


Formula:
calls where:
has_relevance_signal = true
and next_step_proposed = true
and next_step_accepted = true


divided by total calls


Also calculate:
Qualified Next Step Rate From Conversations


Formula:
qualified next step calls / calls with transcript


Reason:
Meeting Rate can be misleading.
The bot may book irrelevant clients.
Qualified Next Step Rate measures meaningful business conversion.

Create:

Priority order:
1. Suspicious No-Transcript / Technical Loss
If many calls have no transcript, especially:
duration_seconds >= 30
duration_seconds >= 60
duration_seconds = 180 or 240
termination_reason = bot_hangup


then main problem is technical/no-transcript risk.
2. Contact to Consent
Test opening phrase.
3. Consent to Offer
Test faster transition to offer.
4. Offer to Relevance Signal
Test offer specificity and qualification question.
5. Relevance to Next Step Proposed
Test transition to action.
6. Proposal to Acceptance
Test next-step framing.
7. Acceptance to Context / Finish
Test post-acceptance context collection.
8. Meeting Without Relevance Signal
Test qualification question before meeting proposal.
15. A/B test generator
Create:
generate_ab_test(recommendation, metrics) -> dict


Return:
{
  "hypothesis": "...",
  "variant_a": "...",
  "variant_b": "...",
  "main_metric": "...",
  "guardrail_metrics": ["...", "..."],
  "expected_effect": "..."
}


For technical bottleneck:
Hypothesis:
A significant part of the loss happens before script optimization is meaningful: some calls have no transcript despite meaningful duration or fixed timeout.
Variant A:
Current call and transcript logging logic.
Variant B:
Review and fix no-transcript handling: fixed timeout, bot_hangup, transcript saving, audio/text logging, and termination statuses. After that, compare Calls With Transcript Rate and suspicious no-transcript volume.
Main metric:
Calls With Transcript Rate


Guardrails:
Bot Hangup Without Transcript
Fixed Timeout Without Transcript
Average Duration of No-Transcript Calls


For offer-to-relevance bottleneck, Variant B:
Мы запускаем AI-продавца в первую линию: он сам прозванивает базу, задаёт первые вопросы и передаёт менеджерам только потенциально релевантных клиентов. Подскажите, у вас сейчас есть база или заявки, которые менеджеры регулярно обзванивают?


For proposal-to-acceptance bottleneck, Variant B:
Давайте сделаем не полноценную встречу, а короткий 15-минутный созвон с экспертом. Он покажет кейс по вашей отрасли и прикинет, есть ли экономика под ваш объём.


For meeting-without-relevance bottleneck, Variant B:
Подскажите, у вас есть база клиентов или заявок, которую менеджеры регулярно прозванивают?
